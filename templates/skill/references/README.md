# References Directory

Deep-dive markdown files go here. Each reference file should be 100-300 lines and cover one specific topic in detail — a topic that is referenced from the main SKILL.md file.

**Guidelines:**

- **One topic per file**: `bdef-syntax.md`, `eml-operations.md`, `managed-vs-unmanaged.md`, etc.
- **Descriptive filename**: Use kebab-case that matches the topic you're documenting.
- **Length**: 100-300 lines per file to keep reference material focused but comprehensive.
- **Format**: Standard markdown with code blocks where appropriate.
- **Mention in SKILL.md**: Every file in this directory must be mentioned by relative path in the main SKILL.md (e.g., `[references/bdef-syntax.md](references/bdef-syntax.md)`).

**Do not put in references/:**
- Quick summaries already in SKILL.md (that's duplication)
- Full ABAP program examples (use `examples/` for working code)
- Tutorial walkthroughs (use the workflow in SKILL.md § Overview and § Workflow for guidance flow)
